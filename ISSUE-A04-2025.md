# A04:2025 – El outbox cifra eventos con AES-ECB y una clave fija

**Estado:** Corregida en `security/vulnerability-fixed`; `security/vulnerability` conserva el patrón vulnerable para comparación.
**Flujo afectado:** Registro de consumo anómalo → outbox PostgreSQL → publicación del evento.

## Ubicación

- En la rama vulnerable, `src/main/java/co/edu/univalle/fleetops/fuel/adapter/out/persistence/OutboxPayloadCipher.java` incluye una clave fija y usa AES/ECB.
- `OutboxJpaAdapter.java` cifra el JSON antes de guardarlo en `outbox_events.payload` y lo descifra al leer eventos pendientes.

## Impacto

Cualquiera que lea el repositorio conoce la clave y puede descifrar los eventos almacenados. ECB produce bloques iguales para bloques de texto iguales y no autentica el mensaje; una modificación del contenido cifrado no tiene etiqueta criptográfica que permita detectarla.

El evento contiene identificadores de vehículo, conductor, ruta y asignación, además del costo, los galones y la eficiencia.

## Reproducción local

1. Configura `OUTBOX_ENCRYPTION_KEY` en `.env` (en la rama fija, genera una clave de 32 bytes con `openssl rand -base64 32`).
2. Inicia el servicio y PostgreSQL según el README.
3. Registra un consumo anómalo: más de 30 % por debajo del promedio después de al menos dos mediciones.
4. Consulta el evento pendiente en PostgreSQL:

```sql
SELECT event_id, payload FROM outbox_events WHERE published_at IS NULL;
```

En la rama vulnerable, el campo tiene un sobre con ciphertext Base64 descifrable con la clave fija del código. En la rama corregida, cada guardado usa AES-GCM con nonce aleatorio; alterar el ciphertext o su etiqueta hace fallar el descifrado.

## Corrección implementada

La rama fija usa AES-GCM y una clave Base64 de 32 bytes leída de `OUTBOX_ENCRYPTION_KEY`, que debe mantenerse fuera del repositorio. La etiqueta se verifica al descifrar. La configuración de prueba usa una clave ficticia.

Empieza con una base vacía al cambiar de rama: los payloads ECB creados por la versión vulnerable no se pueden descifrar con el formato AES-GCM.
