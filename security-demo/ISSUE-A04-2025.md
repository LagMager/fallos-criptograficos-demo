# A04:2025 – Clave AES fija en el código y cifrado ECB

**Severidad del patrón:** Crítica si se usa para datos reales.  
**Estado:** Vulnerabilidad creada intencionalmente para demostración local. No se usa en Fuel Service.

## Ubicación

`security-demo/CryptoDemo.java`, en las constantes de clave y los métodos `encrypt` / `decrypt`.

## Problema

La clave de cifrado está escrita en el código fuente. Cualquier persona con acceso al repositorio puede descifrar todos los valores cifrados con ella, incluso si obtiene los datos mucho después. Además, AES/ECB cifra bloques iguales de forma igual y revela patrones. No autentica el contenido, por lo que tampoco detecta modificaciones de forma segura.

## Reproducción

```sh
javac -d /tmp security-demo/CryptoDemo.java
java -cp /tmp CryptoDemo
```

El programa descifra el dato de muestra usando exclusivamente información presente en el archivo.

## Corrección

Usar AES-GCM con nonce aleatorio único por operación y una clave obtenida de un gestor de secretos o variable protegida, nunca del código. Almacenar el nonce junto al ciphertext y verificar la etiqueta de autenticación al descifrar.
